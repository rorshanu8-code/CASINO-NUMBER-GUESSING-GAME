# 🎰 Casino Number Guessing Game

A simple C++ console game where the player tries to guess a randomly generated number.

## Features
- Easy, Medium, and Hard difficulty levels
- User can choose the number of chances
- Random number generation
- Prize based on difficulty
- Hints: Too High / Too Low
- Simple `if-else` and `while` loop logic

## How to Run
1. Open the program in any C++ compiler or VS Code.
2. Compile and run the code.
3. Select the difficulty level.
4. Enter the number of chances.
5. Guess the random number and win the prize! 🎯
